# Aurelius Universal AI Search Agent — Delivery Package

This package contains the enhanced working project plus the implementation/acceptance documentation and sample exports.

## Start

1. Copy `.env.example` to `.env.local`.
2. Set `OPENAI_API_KEY`.
3. Optional: set `BRAVE_SEARCH_API_KEY`, `EXA_API_KEY`, `TAVILY_API_KEY` for supplemental discovery.
4. Run `npm install`.
5. Run `npm run dev`.

## Production principle

Do not promise "bypass every bot". The system maximizes recall through multiple allowed acquisition channels and records when a source is blocked, unavailable or requires manual review.

## Included examples

The `delivery/examples` directory contains the formatted research exports already produced from the supplied Germany land-search dataset.
