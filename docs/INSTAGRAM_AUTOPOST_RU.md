# AURELIUS: Instagram autopost через Postiz (Sofia)

**Статус:** готовится GitHub PR. Ни одна публикация на Instagram не отправлялась во время разработки.

## Как устроено

1. Фото или видео + утверждённый текст и время попадают через Telegram / Google Sheets в защищённый модуль AURELIUS.
2. АУРЕЛИУС проверяет права на Instagram-аккаунт, корректную дату, медиа и идемпотентный ID.
3. Медиа загружается в Postiz: из Telegram-фотографии через Telegram getFile → Postiz multipart upload, либо по прямой публичной HTTPS-ссылке через Postiz upload-from-url.
4. Запрос Postiz `type: "schedule"` с `__type: "instagram-standalone"`, `post_type: "post"` — Postiz сам выполняет публикацию в назначенное время (не требуется ежеминутный n8n Cron).
5. Сведения о расписании сохраняются в Upstash Redis. `/igstatus` запрашивает Postiz; опубликованным считается только пост с действительной ссылкой `releaseURL`. Если Postiz не вернул ссылку, статус не выдаётся за подтверждённую публикацию.
6. `/igcancel <ID>` удаляет будущую запланированную публикацию из Postiz. Это **не** удаляет уже опубликованный Instagram-пост.

## Предварительные условия

- В Vercel `POSTIZ_API_KEY`, `POSTIZ_ENABLE_SCHEDULE=on`, `SCOUT_ADMIN_KEY`, `TELEGRAM_BOT_TOKEN`, Upstash Redis.
- Добавить `INSTAGRAM_AUTOPOST=on` в Production только после тестов API. До этого новые Instagram-публикации заблокированы.
- Рекомендуется ограничить рабочие аккаунты переменной `INSTAGRAM_ALLOWED_CHANNEL_IDS=<Sofia integration ID>`. ID не является секретом, но нужен точный ID из `/postiz`. Если единственный подключённый Instagram-аккаунт — Sofia, система его выберет автоматически. Если их несколько, нужно явно указать integrationId или allowlist.
- У аккаунта Instagram должны быть права прямой публикации через Postiz OAuth.
- Для реальной публикации обязателен медиафайл; обычный текст без фото/видео никогда не отправляется.
- Использовать только собственный контент, разрешённую рекламу и согласованные права на публикацию. AURELIUS не публикует в сторонних Instagram-профилях.

## Способ A. Telegram — одно фото с командой

В **личном** чате @AURELIUS8_bot отправьте фотографию с подписью:

```
/igqueue 2026-11-25T19:00:00+01:00 | Тестовая фотография и короткий текст для Instagram Sofia.
```

Это **однократное подтверждение задачи** — AURELIUS сразу ставит пост на расписание Postiz. После этого **в назначенный час Postiz публикует без вашего участия**.

Дополнительно текстовая команда с публичным медиа URL:

```
/igqueue 2026-11-25T19:00:00+01:00 | https://ваш-домен.cz/images/photo.jpg | Текст публикации.
```

Дата всегда ISO 8601 с указанием смещения `+01:00` или `+02:00`, не позднее 30 дней вперёд. При публикации из Telegram фото Postiz принимает файл напрямую; публичный URL не нужен.

Проверить: `/igstatus`, отменить: `/igcancel ig-<requestId>`. Уточнение: `/ighelp`.

## Способ Б. Полностью автоматическая очередь из Google Sheets через n8n

Импортировать файл `n8n/aurelius-instagram-approved-autopost.json` в n8n Cloud. Он **выключен** до подключения. Создать Google Sheets `AURELIUS Instagram`, вкладка `InstagramQueue` и столбцы:

| id | status | approvedBy | integrationId | mediaUrl | caption | scheduledAt |
|---|---|---|---|---|---|---|
| ig-sofia-001 | approved | OWNER | id Sofia | https://ваш-сайт.cz/photo.jpg | Утверждённый текст | 2026-11-25T19:00:00+01:00 |

Строку с `approvedBy=OWNER` создаёт/утверждает владелец. Любой другой статус или отсутствие `approvedBy=OWNER` **не запускает публикации**.

Настройка n8n:
1. **Google Sheets OAuth2** в узле «Read approved Instagram queue»; вставить ID таблицы, выбрать вкладку `InstagramQueue`.
2. В HTTP Request узле настроить Header Auth: `x-scout-key` = `SCOUT_ADMIN_KEY` из Vercel. Хранить секрет только в n8n Credentials.
3. Запустить workflow вручную с одной безопасной утверждённой тестовой строкой. Проверить ответ и появление в Postiz Scheduled (не Published).
4. После проверки активировать workflow. Он читает утверждённые строки каждый день в 08:00 по Праге, планирует до 25 задач за запуск; каждую строку AURELIUS идентифицирует по её уникальному `id` и не создаёт второй Postiz-пост при повторном запуске.
5. Postiz самостоятельно публикует по `scheduledAt`; n8n не должен делать отдельный Telegram Trigger для @AURELIUS8_bot.

Чтобы исключить ненужные публикации, удалите `approved` из строк, которые не готовы к размещению. Уже переданные в Postiz задачи нужно отдельно отменить через `/igcancel` или Postiz UI.

## Важные ограничения

- Это автоматическое **расписание подготовленных материалов**, а не разрешение нейросети без проверки публиковать всё найденное в интернете.
- Исходные медиа URL из Google Sheets должны быть стабильными публичными HTTPS-ресурсами JPG, PNG или MP4. Postiz сам проверяет MIME, допустимый размер и защищает от SSRF.
- Уникальный `id` для каждой строки не менять; одинаковые ID не создадут повторные публикации.
- Если Postiz вернул ошибку или timeout, статус «не подтверждено»; возможна отправка на стороне Postiz, поэтому повторять только после проверки календаря. Автоматического рискованного повтора нет.
- Наличие ссылки `releaseURL` означает, что Postiz сообщил об опубликованном посте. Для строгой проверки открывайте ссылку в Instagram.
- Instagram Standalone не поддерживает привязку музыкальной дорожки через Instagram Audio API, поэтому параметры музыки не заполняются.
- Даже при активной автоматике Instagram-аккаунт и контент должны быть одобрены владельцем. Для клиентов Алексея нужны отдельные OAuth-подключения и разрешения, а не чужой аккаунт Sofia.
