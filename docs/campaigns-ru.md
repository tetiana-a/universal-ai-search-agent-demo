# Кампании (ТЗ 1.2): голос → сообщества → размещение → мониторинг → отчёт

## Как пользоваться
1. Отправьте боту **голосовое** (или `/campaign текст`): что рекламируем, где, на каких площадках, сколько в день, текст объявления. Фото: отправьте фото с подписью `/campaign …`.
2. Бот разберёт задачу (бесплатный Gemini/OpenRouter/Groq), задаст уточняющие вопросы (ответьте одним сообщением или голосом) и покажет **40 ключевых слов** и список смежных сообществ. Правка: `/keywords <id> +слово -слово`, свой запрос `/cq <id> …`, исключение `/cx <id> …`.
3. Кнопка **«Слова верны — искать сообщества»**: бот ищет по набору запросов профильные (🟢) и смежные (🟡) сообщества в Telegram, Facebook, Instagram, TikTok, проверяет «живость» (дата и частота постов, порог `INACTIVE_DAYS`, по умолчанию 30 дней), присылает список и Excel.
4. Кнопка **«Запустить размещение»**: каждый день планировщик распределяет кампанию к цели (по умолчанию 300/день) только по площадкам с разрешением:
   - Telegram-чаты, куда админ добавил бота → публикует бот (Bot API);
   - партнёры (админы групп/страниц, согласившиеся публиковать) → бот присылает задание, партнёр публикует сам и отвечает `/proof <задание> <ссылка>`, вы засчитываете кнопкой;
   - остальные разрешённые группы → очередь `/queue` для публикации со своего аккаунта.
   Лимит постов в день и «раз в N дней» задаются на каждую площадку. Без дублей в одну группу.
5. `/monitor <id>` — публикации по ключевым словам в найденных Telegram-каналах (с просмотрами) и публичные посты в поиске. `/capacity` — ёмкость сети и сколько не хватает до 300. `/creport` — отчёт. **`/cstop all` — остановить всё одной командой.**
6. Ежедневно (Vercel Cron, 08:00 UTC, `/api/campaigns/cron`): проверка живости → план дня → задания партнёрам → публикации бота → отчёт в Telegram.

На сайте: страница `/groups` → блоки «Рекламные кампании», «Сегодня», «Площадка партнёра».

## Настройки Vercel (Environment Variables)
- `GEMINI_API_KEY` — бесплатный ключ aistudio.google.com: голосовые, поиск, мониторинг.
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_CHAT_IDS` (ID владельцев), `KV_REST_API_URL`/`KV_REST_API_TOKEN` (база).
- Необязательно: `DAILY_TARGET` (300), `INACTIVE_DAYS` (30), `CAMPAIGN_SEARCH_RUNS` (10 запросов на поиск), `CAMPAIGN_AUTOPOST=off` — выключить автопостинг бота.

## Чего нет и почему
Нет ферм аккаунтов, обхода защит и автоматической публикации с личных аккаунтов: это запрещено правилами Facebook/Telegram и ведёт к блокировкам. Meta Graph API / TikTok API для своих страниц подключаются отдельно после проверки приложения платформой. Мониторинг закрытых групп невозможен.
