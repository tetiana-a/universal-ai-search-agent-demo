# Две версии: Free и Pro

Один и тот же агент работает в двух редакциях. Редакция определяется тарифом посетителя
(`lib/plans.ts`): без ключа доступа — Free, с ключом из `PRO_ACCESS_KEYS` — Pro.

## Free — работает без единого платного ключа

| Этап | Что используется | Ключ |
|---|---|---|
| Поиск | DuckDuckGo (HTML-выдача) | не нужен |
| Поиск (опционально, стабильнее) | свой SearXNG — `SEARXNG_URL` | не нужен |
| Поиск (опционально) | Jina Search — `JINA_API_KEY` (бесплатный ключ с лимитом токенов) | бесплатный |
| Чтение страниц | Jina Reader без ключа, при отказе — прямое чтение с учётом robots.txt | не нужен |
| AI-извлечение | OpenRouter free-модели → Gemini free tier → Groq free tier, по очереди | бесплатные ключи |
| Без AI-ключа | извлечение полей правилами (цена, площадь, контакты, чек), статус «Manual review» | — |
| База источников | Upstash Redis (Vercel Marketplace, бесплатный план) | бесплатный |

Если DuckDuckGo просит проверку «человек ли вы», это показывается как `rate_limited`; обход не выполняется.

## Pro

То же самое, плюс:
- больше веток поиска (10 вместо 6), источников (до 60 за раунд) и прочитанных страниц (14 вместо 8);
- платные поисковые API, если заданы (`BRAVE_SEARCH_API_KEY`, `TAVILY_API_KEY`, `EXA_API_KEY`, `SERPER_API_KEY`, …);
- более сильная модель через OpenRouter: `PRO_OPENROUTER_MODEL` (например `anthropic/claude-sonnet-4.5` или `openai/gpt-5-mini`), или `PRO_GEMINI_MODEL`;
- если задан `OPENAI_API_KEY`, Pro-задачи идут в OpenAI deep research с web search (фоновые задачи);
- экспорт XLSX/PDF, Telegram и e-mail.

## Переменные окружения

| Переменная | Для чего | Обязательна |
|---|---|---|
| `OPENROUTER_API_KEY` | бесплатные AI-модели (`openrouter/free`) | рекомендуется |
| `GEMINI_API_KEY` | запасной бесплатный AI (Google AI Studio) | нет |
| `GROQ_API_KEY` | ещё один запасной бесплатный AI | нет |
| `JINA_API_KEY` | более стабильные поиск и чтение | нет |
| `SEARXNG_URL` | свой SearXNG с включённым `format=json` | нет |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | постоянная база источников и лимиты (Upstash) | рекомендуется |
| `PRO_ACCESS_KEYS` | ключи доступа к Pro через запятую (от 12 символов) | для Pro |
| `PRO_OPENROUTER_MODEL` | платная модель для Pro | нет |
| `OPENAI_API_KEY` | OpenAI deep research для Pro | нет |
| `RESEARCH_AI_PROVIDER` | `auto` (по умолчанию), `free` — всем бесплатный конвейер, `paid` — всем OpenAI | нет |
| `KEYLESS_SEARCH` | `off` — выключить поиск без ключа, `always` — использовать вместе с Jina | нет |
| `DIRECT_READ` | `off` — не читать страницы напрямую | нет |

Внимание: если в Vercel уже стоит `RESEARCH_AI_PROVIDER=free`, Pro никогда не пойдёт в OpenAI. Уберите переменную или поставьте `auto`.

## Управление задачей (по ТЗ)

- **Уточняющие вопросы**: `POST /api/research/clarify` возвращает тип задачи, вопросы только о незаданных критериях и колонки результата. Ответы передаются в `clarifications` и добавляются к запросу.
- **Счётчики прогресса**: в ответе `progressCounters` — обнаружено, в базе, проверено, недоступно, найдено, после дублей, соответствуют критериям, нужна проверка.
- **Стоп / изменить / продолжить**: стоп прерывает запрос; «Продолжить» отправляет `continuation: { round, excludeUrls }`, сервер берёт следующие ветки поиска и не перечитывает уже проверенные страницы. Если текст запроса изменён, продолжение идёт по новым критериям, результаты раундов объединяются без дублей.
- **Адаптивные поля**: `fieldSchema` в ответе задаёт колонки под тип задачи (недвижимость, инвесторы, компании, люди, общий).

## Ограничения бесплатной версии

- DuckDuckGo без ключа может временно ограничивать запросы с серверов Vercel; для стабильности добавьте `JINA_API_KEY` или `SEARXNG_URL`.
- Без AI-ключа поля извлекаются правилами, и все результаты помечаются для ручной проверки.
- Бесплатная задача должна уложиться в 60 секунд (Vercel Hobby), поэтому за раунд читается до 8 страниц; глубину добирают кнопкой «Продолжить».
- Соцсети и сайты с логином или CAPTCHA не исследуются автоматически, они попадают в ручную проверку.
