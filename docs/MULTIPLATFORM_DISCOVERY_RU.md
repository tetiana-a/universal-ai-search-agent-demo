# AURELIUS — автоматическое определение площадок Instagram / Telegram / TikTok / Facebook

## Входной запрос

Бот получает от Алексея голосом либо текстом: «Найди активные сообщества о квартирах в Валенсии, Испания, на испанском и английском в Telegram, Instagram и TikTok».

Из уже существующего модуля кампаний берутся тема, география, языки и выбранные платформы. Если пользователь упомянул определённые сети, приложение автоматически выбирает именно их; если не назвал ни одной — ищет сразу на четырёх платформах.

В панели `/groups` есть поле страны/города/темы и переключатель «Все платформы автоматически» либо отдельной сети. В кампаниях список платформ содержится в извлечённой AI-моделью задаче.

## Реальный поиск

1. По выбранной теме создаются две очереди запросов для каждой платформы. Первая очередь ищет по одному запросу в каждой сети — ни одна сеть не остаётся в конце списка.
2. Telegram: общедоступные группы и каналы, проверяемые по публичному t.me preview. Дополнительно TGStat при включённом лицензированном `TGSTAT_SEARCH_ENABLED=on`.
3. Instagram: общедоступные тематические аккаунты и страницы компаний, URL формата instagram.com/username. Instagram-посты, рилсы, системные страницы и приватные аккаунты исключаются.
4. TikTok: публичные тематические авторы, URL tiktok.com/@username. Ссылка на видео того же автора нормализуется до профиля; теги и поисковые страницы исключаются.
5. Facebook: публичные страницы групп facebook.com/groups/..., когда ссылки индексируются.
6. Источники: публичный индекс DataForSEO (опционально и оплачивается отдельно); DuckDuckGo/SearXNG при доступности; ограниченная резервная модель Gemini только если ранее не были получены ссылки для требуемой платформы.
7. Кандидаты дублируются по нормализованному URL, помечаются исходным поисковым запросом. Страницы Telegram проверяются, а профили Instagram/TikTok остаются с меткой `indexed_candidate`, `activity=unknown`, `ads=unknown`, `status=new`.
8. Актуальная активность, число подписчиков и условия размещения Instagram/TikTok **не определяются из поисковой выдачи**. Для этих полей требуется отдельный авторизованный источник и проверка.

## Не путать поиск с публикацией

- У Telegram есть группы и каналы, у Instagram/TikTok — профили, но нет аналога Telegram-групп с публичным API для массовых чужих объявлений.
- Поиск публичного профиля не даёт право публиковать у владельца или рассылать ему рекламные сообщения. Статус кандидата по умолчанию не входит в разрешённую автоматическую очередь.
- В Postiz авторизуются собственные или клиентские аккаунты; публикации на чужих аккаунтах требуют согласия владельца.
- TikTok Research API и Meta Content Library/Research API могут иметь ограничения на доступ и коммерческое использование. Никаких обходов CAPTCHA, неавторизованного доступа и выдуманных контактных данных.

## Подключения в Vercel

- Существующие ключи OpenAI, Gemini, Telegram, Postiz и Upstash Redis остаются — новых Telegram API-ключей для поиска не нужно.
- Для более стабильного публичного поиска: `DATAFORSEO_LOGIN` и `DATAFORSEO_PASSWORD`, после проверки расходов `DATAFORSEO_GROUP_SEARCH=on`.
- Для Telegram-источника при наличии подписки: `TGSTAT_TOKEN` и `TGSTAT_SEARCH_ENABLED=on`.
- В отсутствие внешних поисковых данных приложение может корректно вернуть ноль с сообщением об ограниченной доступности, а не выдумывать соцсети или контакты.
- Каждая итерация поиска по теме делает максимум по одному платному DataForSEO-запросу для каждой из выбранных платформ, максимум четыре. При `CAMPAIGN_SEARCH_RUNS=10` это может быть до 40 платных запросов за одну кампанию; рекомендуется начать с `CAMPAIGN_SEARCH_RUNS=2` или `4` и бюджета провайдера.

## Проверка на тестовом запросе

Тема: «продажа квартир»; регион: «Валенсия, Испания»; площадки: Telegram, Instagram, TikTok.

Проверить: (а) запросы адаптированы к региону и платформам; (б) прямые ссылки без повторов; (в) указана исходная поисковая фраза; (г) IG/TikTok помечены как кандидаты; (д) в отсутствии разрешений ни одна публикация не выполняется.
