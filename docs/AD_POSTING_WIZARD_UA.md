# AURELIUS — розміщення оголошень через Telegram

## Як користуватися

У приватному чаті власник пише «нужно разместить объявление», «Хочу розмістити оголошення» або /ad, або натискає кнопку «📣 Разместить объявление» в головному меню.

1. Географія: місто і країна, наприклад «Валенсия, Испания».
2. Оголошення: точний текст від власника (15–3500 символів). Можна надіслати фотографію з підписом; ціни та контактні дані не повинні змінюватися.
3. Соцмережі: Telegram, Facebook, Instagram, TikTok, комбінації або всі чотири. Можна відповідати текстом або кнопкою.

Після заповнення створюється лише чернетка. Бот показує текст, регіон, соцмережі й ключові слова та пропонує кнопку «🔎 Найти площадки для объявления». Пошук — окреме підтвердження, а початок розміщення — ще одне окреме підтвердження після результатів пошуку.

Telegram Bot API публікує автоматично тільки в чатах, куди адміністратор додав бота і надав права. Для Facebook, Instagram, TikTok та інших спільнот застосовуються погоджені партнерські завдання або ручна черга. Автоматичне розміщення без дозволу не підтримується.

Скасування: кнопка «✖️ Отменить», текст «отмена» або /cancel. Для готових кампаній — /cstop <id>; для всіх — /cstop all.

## Технічна примітка

Нова функція зберігає тимчасову анкету на 24 години в Redis та доступна лише власникам/адміністраторам у приватному чаті. Передачу кампанії на масове розміщення не виконує. Для надійного production-збереження потрібен налаштований Upstash Redis.

Перед ввімкненням реклами в production інтегруйте зміни безпеки з PR #41, встановіть SCOUT_ADMIN_KEY і CRON_SECRET, перевірте права Telegram та виконайте тест на дозволеному каналі.

## Перевірка вручну

- Надіслати «нужно разместить объявление» — має прийти запит географії, а не загальне «Новая задача».
- Відповісти «Валенсия, Испания» — має прийти запит тексту.
- Надіслати текст або фото з підписом — має з'явитися вибір платформ.
- Вибрати Telegram + Facebook — створюється лише чернетка.
- Перевірити, що в журналі немає нового фактичного поста без схвалення.
- Виконати «отмена» на першому або другому кроці — чернетка не створюється.
